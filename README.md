> **QuickUPI Invoice** is a free, 100% client-side invoice generator tailored for Indian freelancers, creators, and small businesses. Generates professional A4 PDF bills featuring a dynamic, scan-to-pay UPI QR code with auto-filled payment amounts.

---

## 🌐 Live Web App

Use the tool directly in your browser with zero sign-up:  
👉 **[Open QuickUPI Invoice](https://gautamnox7-debug.github.io/quick-upi-invoice/)**

---

## 🌟 Key Highlights & Features

- 🇮🇳 **Dynamic UPI QR Code**: Uses standard `upi://pay` protocol compatible with Google Pay, PhonePe, Paytm, BHIM, CRED, and all Indian banking apps.
- ⚡ **Exact Amount Prefilled**: When your client scans the QR code from the PDF, the payee name and exact bill amount are already entered!
- 🔒 **100% Private & Local**: Zero databases. Your financial info never leaves your browser.
- 🖨️ **1-Click PDF & Vector Print**: Export pixel-perfect A4 invoice PDFs in one click.
- 💰 **Auto Tax / GST Calculations**: Instant calculation for 0%, 5%, 12%, and 18% GST slabs.

---

## 🛠️ How to Run Locally

```bash
git clone https://github.com/gautamnox7-debug/quick-upi-invoice.git
cd quick-upi-invoice
```
Open `index.html` in any browser. That's it! No npm, no node_modules, no server needed.
